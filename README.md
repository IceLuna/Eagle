# Eagle Engine
Welcome to Eagle Engine - the free and open source game engine that is currently available on Windows.

[![Documentation Status](https://readthedocs.org/projects/eagledocs/badge/?version=v0.7)](https://eagledocs.readthedocs.io/en/v0.7/)

<p align="center">
    <img src="docs/source/rendering/imgs/volumetric_light_2.png" alt="Eagle Engine">
</p>

## Main features
- C# scripting with quick hot reloading support
- Physics
- Audio
- Navigation meshes & crowd system
- Modern rendering
  - Physically based rendering
  - Image-based lighting with multiple scattering
  - Order-independent translucency
  - Opaque, translucent, and masked materials
  - Point, spot, and directional lights
  - Soft shadows, and cascades shadow maps
  - Translucent shadows (colored shadow maps)
  - Volumetric lights and fog
  - Ambient occlusion (SSAO, GTAO)
  - Bloom
  - Text rendering (MSDF atlas)
  - Anti-aliasing (TAA)
  - Skeletal animations
  - Node based animation graphs
  - GPU Particle system
  - Depth of Field
  - Motion Blur
  - Screen-space reflections
  - Deferred decals
- Project & asset managers
- Game builds
- Play in editor
